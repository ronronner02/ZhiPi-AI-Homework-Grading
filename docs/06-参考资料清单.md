## 三、学术研究（技术现状与公认局限）

17. **Large Language Model-Powered Automated Assessment: A Systematic Review**
    - 来源：Applied Sciences（MDPI）｜2025
    - URL：https://www.mdpi.com/2076-3417/15/10/5683
    - 关联：系统综述指出 LLM 自动评估存在 bias、inconsistency、hallucination、可解释性有限、隐私等局限，主观/创造性场景尤甚——本方案"红黄绿分流 + 教师复核"的核心学术依据。

18. **Can AI Assistance Aid in the Grading of Handwritten Answer Sheets?**
    - 来源：arXiv:2408.12870｜2024
    - URL：https://arxiv.org/pdf/2408.12870
    - 关联：实证 AI 辅助使单个答案评分时间降低约 31%、整份答卷降低约 33%（跨 4 门课/17 名评分者/468 份），即设计方案 §18.1 引用数据的原始出处。

19. **Human-in-the-Loop LLM Grading for Handwritten Mathematics Assessments**
    - 来源：arXiv:2603.13083｜2026
    - URL：https://arxiv.org/html/2603.13083
    - 关联：人在回路方案（多轮 LLM 评分 + 一致性检查 + 强制人工复核）减少约 23% 批改时间且一致性与全人工相当，直接支撑本方案"教师可控"机制设计。

20. **Automated Grading of Handwritten Mathematics Using Vision-Capable LLMs**
    - 来源：arXiv:2605.19043（University of Illinois 相关研究）｜2026
    - URL：https://arxiv.org/abs/2605.19043
    - 关联：发现最佳模型约 87% 的错误源于转写失败而非评分逻辑，常见错误含图像质量、幻觉内容、等价表达式误判——论证 OCR 前处理与置信度分流的必要性。

21. **On Automated Essay Grading using Large Language Models**
    - 来源：ACM（2024 8th Intl. Conf. on Computer Science and AI）｜2024
    - URL：https://dl.acm.org/doi/10.1145/3709026.3709030
    - 关联：作文自动评分中 LLM 未持续超越人类评分者、对 Rubric 措辞敏感，支撑"作文/主观题需人工把关"论点。
