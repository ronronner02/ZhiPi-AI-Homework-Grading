# 批改样例与数据分析样本

> 本文对应命题交付要求"批改样例展示：输入作业图片 → 输出批改结果 + 评语 + 薄弱点分析"。第一部分逐份解读 `samples/` 下三份样例（数学 / 物理 / 英语），第二部分为模拟班级学情样本，第三部分说明数据口径。字段与规则遵循详细设计方案 §6、§9、§14。

## 一、批改样例解读

三份样例覆盖三个学科、三种置信度分流、三种教师处理方式，完整演示系统的四个核心卖点：**部分正确给过程分、错因归因、红黄绿分流、教师可控**；统一采用"输入（题目 / 标准答案 / Rubric / 手写图片描述 / OCR 转写）→ AI 过程级批改 → 教师审核 → 薄弱点分析"结构，字段与设计方案 §9.5、§14.3、§15.1 一致。

### 样例一：数学·配方法解一元二次方程（绿色·教师确认）

**输入。** 题目为"用配方法解 x² - 6x + 5 = 0"。手写图片描述记录字迹工整、`(x-3)²=3` 处的"3"有轻微描重；OCR 忠实转写学生五行作答，保留其错误。学生的作答链条是：`x²-6x=-5 → x²-6x+9=-5+9 → (x-3)²=3 → x=3±√3`。

**AI 如何逐步批改。** 系统按设计方案 §6.2 的批改节点把题目拆为"移项 → 配方 → 计算右边 → 开方求解"四步，对照 Rubric 逐项给分：

```json
"step_analysis": [
  {"step": "移项",   "is_correct": true,  "score": 2, "max_score": 2},
  {"step": "配方",   "is_correct": true,  "score": 3, "max_score": 3},
  {"step": "计算右边并化简", "is_correct": false, "score": 0, "max_score": 2,
   "reason": "-5 + 9 应等于 4，学生算成 3，写成 (x-3)²=3，属计算错误。"},
  {"step": "开方求解", "is_correct": false, "score": 2, "max_score": 3,
   "reason": "开方操作本身规范……因上一步数值算错导致最终解错误，属将错就错。保留开方方法分 2 分，扣最终答案 1 分。"}
]
```

**为何给过程分。** 学生方法选择完全正确（配方、开方思路无误），仅在"-5+9"这一处算术上失误并"将错就错"。系统没有因最终答案错就判零分，而是保留了移项（2）、配方（3）、开方方法（2）共 7 分，只在出错的计算步扣满、在被连累的最终答案步扣 1 分，最终 **7/10**。这正是"识别部分正确的解题过程并给予过程分"的直接体现。

**为何是"计算错误"标签。** 学生的公式与推理链都对，错误精确定位在一次常数合并运算，因此错因标签取自设计方案 §6.11 第二层枚举中的 `计算错误`，而非概念或公式类标签。

**为何落入绿色。** OCR 清晰、方法路径明确、错误位置唯一且可解释，`confidence = 0.91 ≥ 0.85`，按 §9.7 分流规则判为 `green`，AI 自动通过、教师抽查即可。

**教师如何处理 / 学生看到什么。** 教师动作为 `confirmed`，终分维持 7 分。学生看到的评语（≤80 字，先肯定后建议、不空泛）：

> 配方法思路和配方步骤都正确，方法你已掌握。问题在第三步：-5+9应得4，你算成3，后面便将错就错。下次配方后把两边数值再核对一遍，就能拿满分。

### 样例二：物理·欧姆定律与并联电路（黄色·教师修改）

**输入。** 题目为 R1=6Ω 与 R2=3Ω **并联** 接 U=6V，求总电阻与干路电流。OCR 转写显示学生首句即写"这是串联电路"，随后 `R=R1+R2=9Ω`、`I=U/R=6/9≈0.67A`。

**AI 如何逐步批改与错因归因。** 系统按"电路结构识别 → 公式选择 → 数值代入 → 最终答案"四节点批改，关键在于**归因深度**：

```json
"step_analysis": [
  {"step": "电路结构识别", "is_correct": false, "score": 0, "reason": "R1、R2 为并联，学生写为『串联电路』，属图形理解错误。"},
  {"step": "公式选择",   "is_correct": false, "score": 0, "reason": "应选并联公式 R=R1·R2/(R1+R2)，学生用串联公式，属公式选择错误；根源是上一步结构识别错误。"},
  {"step": "数值代入",   "is_correct": false, "score": 1, "reason": "就其所选（错误）公式而言，6+3=9、6/9≈0.67 的运算本身没有算术错误……保留运算规范分 1 分。"}
]
```

系统识别出：学生的**代入与运算完全没有算术错误**，最终答案之所以错，是因为最上游把并联误判为串联，进而选错公式。因此错因标签是"图形理解错误 + 公式选择错误"的**组合**，且明确指出前者是后者的根因——这是"模型错"而非"算错"。这种因果链归因，是普通"只报知识点"的系统给不出的。

```json
"error_tags": ["图形理解错误", "公式选择错误"],
"confidence": 0.72,
"triage": "yellow"
```

**为何落入黄色。** 电路结构的图形判断本身存在识别不确定性，"代入步骤是否给规范分"也需人工定夺，`confidence = 0.72`，落在 `0.60 ≤ c < 0.85`，按 §9.7 判为 `yellow`，AI 给出建议、教师一键确认或微调。

**教师如何处理（可控性）。** 教师动作为 `modified`：认可学生欧姆定律运用规范、代入无算术错误，把"数值代入"由 1 分调为满分，总分由 AI 建议的 1/8 **微调为 2/8**，并补充评语点明"根因是并联误判为串联"。这演示了教师对分数与评语的完全可控。学生看到的评语：

> 你欧姆定律I=U/R用得很熟，代入运算都没错。问题在最前一步：这是并联不是串联，总电阻应按并联算得2Ω、总电流3A。以后先判断电路是串还是并，再选公式。

### 样例三：英语·看图写话片段（红色·转人工）

**输入。** 题目要求 60~80 词描述"上周末做了什么"（图片：与家人到公园野餐、踢球、拍照），Rubric 按 **内容 / 结构 / 语法 / 词汇** 四维度给分（5/3/4/3，共 15 分）。学生作答约 60 词，OCR 转写忠实保留错误，并对一处潦草单词标注不确定：

```
Last weekend, I go to the park ... The wether is sunny and very beatiful.
We have a picnic ... My father and I play football ... I very like this day.
We [潦草，OCR 在 take / took 间不确定] many nice photos. I hope go there again ...
```

**AI 如何逐步批改。** 系统按四维度评分：内容要点（时间、地点、人物、活动、感受）齐全，给满分 5/5（**先肯定内容完整性**）；结构基本连贯但衔接词少，2/3；语法上叙述过去却系统性用一般现在时（go/is/have/eat/play），1/4；词汇上有 `wether→weather`、`beatiful→beautiful` 两处拼写错误与 `very like` 中式表达，1/3。

**错因标签映射。** 英语作文错因需映射到设计方案 §6.11 的统一错因枚举：时态误用 → `概念理解错误`（时态语法概念）；两处拼写 → `符号书写错误`；中式表达 → `表达不完整`（表达不规范 / 不地道）。知识点则取 `英语时态`。

**为何落入红色。** 倒数第二句主要动词字迹潦草，OCR 在 take/took 间无法确定（识别置信度低），叠加书面表达评分的主观性，综合 `confidence = 0.55 < 0.60`，按 §9.7 判为 `red`。此时 AI **不自动判分**，9/15 仅作参考建议，整题转人工。

**教师如何处理。** 教师动作为 `modified`：辨读潦草词后据 Rubric 复核，终分定为 10/15，并给出体现"先肯定内容完整 → 指出时态问题 → 一条可执行建议"结构的终评：

> 内容完整，时间、地点、活动、感受都写到了，很好。最需要改进的是时态：上周末的事要用一般过去时，不能用现在时。建议重写时先把每个动词都改成过去式，再检查两处拼写。

三份样例串起来，恰好演示了系统在"高置信自动通过、中置信教师确认、低置信转人工"三档下的差异化行为，以及从判分、归因到评语、审核的完整闭环。

## 二、模拟班级学情分析样本

> **以下为模拟数据，用于演示系统的分析口径与报告形态，非真实采集数据。**

### 三名典型学生画像片段

**① 进步型——王雨（化名）。** 本次 8 题对 7，唯一错题在 Q7（混联识别，图形理解错误）。系统调取其历史画像：近三次作业"计算错误"占比 40% → 22% → 9% **连续下降**，说明计算已趋于稳定，当前薄弱迁移到"混联电路识别"。系统判定为"从不会到掌握、计算转稳"的进步型，补救指向直接进阶综合题。

**② 粗心型——陈浩（化名）。** 本次 8 题对 6，两道错题（Q2、Q5）**均含单位错误**；而串并联识别类题（Q4、Q6）全部做对，说明概念清楚。历史画像显示单位错误近三次每次≥2 处、反复出现。系统判定为"会做但粗心、单位失分型"，补救指向单位换算与解题规范的限时专项、强制"回看单位"。

**③ 概念缺失型——刘洋（化名）。** 本次 8 题仅对 3，5 道错题集中在 Q4、Q6、Q7、Q8 与 Q5，错因为图形理解错误（Q4/Q6/Q7）叠加概念理解错误（Q8）；串并联相关题正确率不足 30%。因"串并联识别"这一知识点连续三次作业出错，触发设计方案 §6.16 的**学习风险预警**。补救需从串并联识别的基础概念补起，先只判结构、不计算，过关后再进入计算。

三名学生的错因分布与全班一致（图形理解错误为首、单位错误其次），且个体数字均落在对应题目的答错人数之内，与表 1–表 4 不矛盾。

### 基于数据自动生成的下节课讲评建议

依据上述聚合结果，系统按设计方案 §15.3 的格式生成讲评方案：

1. **班级主要问题。** 头号薄弱是"串并联电路识别"——错因分布中"图形理解错误"以 38 次（25.5%）居首，且是 Q4、Q6、Q7 的主要错因，更是 Q5–Q8 公式选择错误（24 次）的上游根因；其次是电功率综合应用（Q8 正确率仅 33.3%）与单位规范性（单位错误 30 次）。
2. **下节课讲评顺序**（按知识依赖，先根因后综合）：① 串并联识别（用实物 / 动画对比串、并联结构，训练"先辨结构再动笔"）→ ② 串并联中的电压 / 电流分配规律（衔接 Q5、Q6）→ ③ 欧姆定律在混联电路中的应用（Q7）→ ④ 电功率综合（Q8，辨析 P=UI / P=I²R / P=U²R 的选用）。
3. **分层辅导。** 进步型（如王雨）跳过基础、直接做混联 + 电功率拔高题；粗心型（如陈浩）做单位换算与规范书写限时训练；概念缺失型（如刘洋）从串并联识别基础概念补起。
4. **复测题。** 布置 5 题——2 题串并联识别（纯判别）、1 题串 / 并联对照计算、1 题混联、1 题电功率综合，下次作业作为复测，重点跟踪"图形理解错误"占比是否下降。

## 三、数据口径与字段说明

各表均由批改结果表 `question_results`（每份提交每题一条记录，字段见设计方案 §10.1、§14.3：`final_score`、`max_score`、`confidence`、`triage`、`error_tags`、`knowledge_points`）聚合而来，聚合口径如下。

- **题次基数。** 45 人 × 8 题 = 360 条记录 = 360 题次；表 1 正确 + 答错、表 4 绿 + 黄 + 红均以 360 为总量闭合。
- **表 1（逐题）。** 正确人数 = 该题 `final_score == max_score`（得满分）的人数；答错人数 = 45 − 正确人数（含部分正确者）；正确率 = 正确人数 ÷ 45；主要 / 次要错因 = 该题所有记录的 `error_tags` 按出现频次排序取前两位。
- **表 2（知识点错误率）。** 先建立"题目 → 知识点"映射（一题可映射多个知识点）；某知识点错误率 = 映射到它的题目集合上的答错人次 ÷ 该集合总答题人次。分母因多重映射而重叠，故本表只用于排序、不加总。
- **表 3（错因分布）。** 对全部 360 条记录的 `error_tags` 逐一计数；标注口径为每道错题 1~2 个错因（主错因必有，次错因视连带成因而定），故总次数（149）≥ 答错题次（119）；占比 = 各标签次数 ÷ 149。
- **表 4（红黄绿分流）。** 按每条记录的 `triage` 统计；分流阈值取自 §9.7：`confidence ≥ 0.85` 绿、`0.60 ≤ confidence < 0.85` 黄、`confidence < 0.60` 红。AI 自动通过率 = 绿 ÷ 360；需教师处理量 = 黄 + 红；耗时估算 = 各类题次 × 假设单题耗时（纯人工基准 45 s，绿色抽查 10 s、黄色一键确认 20 s、红色人工批改 45 s）。此处的分流反映 AI 置信度而非答案对错。
- **学生画像。** 高频错因、薄弱知识点、进步趋势、学习风险由该生历史 `error_tags` 与得分序列按设计方案 §6.15–§6.16 聚合；"同一知识点连续三次出错"即触发学习风险预警。

以上口径保证四张表、学生画像与三份样例之间数字一致：三份样例中出现的"计算错误""图形理解错误 + 公式选择错误""概念理解错误"等标签，正是班级错因分布表中的统计对象；样例二暴露的"并联误判为串联"，正是班级头号薄弱点"串并联电路识别"的微观个案。
